# Cuentas Claras

Lista de gastos para anotar fecha, descripción y si fue en efectivo o con tarjeta. Suma el total, reparte lo que debe cada persona con su fecha de pago, y cierra el día o los días para guardarlos y empezar otra lista.

Los gastos permanecen en el teléfono. El tipo de cambio USD/EUR a MXN se consulta en vivo en [Frankfurter](https://www.frankfurter.app), sin enviar datos personales.
